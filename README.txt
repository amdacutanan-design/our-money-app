Mālama Journey V4.2

Adds a working credit-card statement scanner for screenshots/photos and text-based PDFs. Review and tag every detected purchase before import. Likely payments/credits are unchecked by default. Duplicate imports are detected using a fingerprint stored in external_reference. Raw statement files are processed in the browser and are not stored in Supabase.

No additional Supabase migration is required if V4.1 stability migration has already been run.
